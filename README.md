## 重构概述

本次重构在保留旧版 Vue + Express 代码的同时，新增了**前后端分离的 HTML5 + FastAPI 技术栈**：

- **前端**：`ai-sport/html-frontend/index.html` 使用原生 HTML5 + JavaScript + Canvas 获取摄像头数据并调用后端接口。
- **后端**：`ai-sport/python-backend` 基于 FastAPI，集成 MediaPipe + OpenCV 进行姿态识别，SQLAlchemy + SQLite 写入训练记录，Pandas + Matplotlib 完成数据聚合与图表输出。
- **数据通路**：前端每 2 秒推送一帧到 `/api/pose/analyze`，后端返回关键点、评分、动作计数并可写入数据库；`/api/analytics/chart.png` 直接输出趋势图供前端展示。

启动方式与接口说明详见 `ai-sport/python-backend/README.md`。

## 系统概述

AI Sport 是一个基于人工智能的运动姿态识别与分析系统，旨在帮助用户进行居家健身和运动训练。该系统通过前端摄像头实时检测用户运动姿态，提供即时反馈和指导，并记录运动数据以供后续分析。

## 核心功能

### 1. AI 运动检测
- **实时姿态识别**：使用 TensorFlow.js 和 MoveNet 模型进行实时人体姿态检测
- **动作质量评估**：对运动姿态进行 0-100 分的质量评分
- **智能计数**：仅计算质量达标（≥60%）的标准动作
- **骨架可视化**：直观显示用户运动姿态和关键点

### 2. 运动类型支持
- **俯卧撑检测**：评估身体平直度、手臂对称性、下降深度和手部位置
- **深蹲检测**：评估下蹲深度、膝盖对齐、上身挺直和脚部稳定性
- **可扩展支持**：系统架构支持添加更多运动类型

### 3. 用户账户管理
- **用户注册与登录**：支持账户创建和身份验证
- **个人资料管理**：用户可管理个人信息和偏好设置
- **头像上传**：支持自定义用户头像
- **个人成就**：展示运动成就

### 4. 运动数据记录与分析
- **训练历史记录**：保存每次训练的详细数据
- **统计分析**：总训练次数、总时长、连续训练天数等统计
- **AI 检测数据**：记录平均置信度、准确率、检测帧数等技术指标
- **用户反馈**：收集用户对训练体验的评价
- **数据可视化**：图表展示训练趋势和进步情况

### 5. 签到系统
- **每日签到**：用户每日签到获取积分和经验奖励
- **连续签到**：连续签到获得额外奖励，系统自动计算连续天数
- **签到日历**：可视化展示月度签到历史记录
- **积分奖励**：签到获得积分，连续签到有额外奖励
- **自动签到**：运动完成后可自动签到
- **补签功能**：支持补签最近7天的签到记录
- **签到排行榜**：展示好友间的签到排名和统计

### 6. 运动计划管理
- **计划创建**：创建个性化的多周运动计划
- **计划模板**：提供不同难度和类型的预设计划模板
- **进度跟踪**：实时跟踪每日、每周的计划执行进度
- **今日计划**：显示当天的具体运动安排
- **计划分享**：可以分享运动计划给其他用户
- **完成统计**：记录计划完成情况和运动数据

### 7. 智能提醒系统
- **运动提醒**：基于用户设定时间的定时运动提醒
- **个性化设置**：自定义提醒时间、提醒日期和提醒消息
- **浏览器通知**：支持浏览器推送通知提醒

### 8. 好友圈社交功能
- **好友管理**：添加好友、查看好友列表和运动状态
- **运动邀请**：邀请好友一起进行实时运动挑战
- **好友排行**：查看好友间的运动数据排行榜
- **活动状态**：显示好友今日运动状态和连续运动天数
- **邀请会话**：支持好友间的运动邀请和实时进度同步
- **好友请求**：处理好友添加请求和管理

### 9. 音频反馈系统
- **语音指导**：提供运动动作指导的语音提示
- **计数音效**：完成标准动作时的音效反馈
- **倒计时提示**：训练开始前的语音倒计时
- **背景音乐**：支持运动时播放背景音乐
- **音效自定义**：用户可选择不同的音效主题


## 技术架构

### 前端 (ai-workout-vue)
- **核心框架**：Vue 3 + Composition API + TypeScript
- **UI 组件库**：Element Plus (现代化组件库)
- **构建工具**：Vite (快速构建和热重载)
- **样式框架**：Tailwind CSS (原子化CSS框架)
- **AI 引擎**：TensorFlow.js + MoveNet (实时姿态检测)
- **状态管理**：Pinia (Vue 3 官方推荐状态管理)
- **路由管理**：Vue Router 4
- **HTTP 客户端**：Axios (API请求处理)
- **代码规范**：ESLint + Prettier
- **开发工具**：Vite DevTools, Vue DevTools

### 后端 (backend)
- **运行环境**：Node.js (JavaScript 运行时)
- **Web 框架**：Express.js (轻量级 Web 框架)
- **数据库**：MongoDB (NoSQL 文档数据库)
- **ODM**：Mongoose (MongoDB 对象文档映射)
- **认证系统**：JWT (JSON Web Token) + bcrypt (密码加密)
- **API 设计**：RESTful API 架构
- **安全中间件**：
  - Helmet (HTTP 头安全)
  - Express Rate Limit (请求频率限制)
  - CORS (跨域资源共享)
- **环境配置**：dotenv (环境变量管理)
- **开发工具**：nodemon (自动重启)

### 部署与运行选项

#### 本地开发环境
- **支持系统**：Windows, macOS, Linux
- **Node.js 版本**：≥ 21.7.3
- **包管理器**：npm 或 yarn
- **数据库**：本地 MongoDB 或 MongoDB Atlas

#### Docker 容器化部署
- **容器编排**：Docker Compose
- **一键启动**：支持完整系统容器化部署
- **服务包含**：
  - 前端 Vue 应用容器
  - 后端 Node.js API 容器
  - MongoDB 数据库容器
  - Nginx 反向代理容器
- **环境隔离**：开发、测试、生产环境配置分离
- **数据持久化**：MongoDB 数据卷挂载
- **网络配置**：内部服务网络通信
