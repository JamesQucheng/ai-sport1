## 🚀 快速开始

### 1. 安装依赖
```bash
cd ai-workout-vue
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问 `http://localhost:8080`

## 🛠️ 技术架构

- **前端框架**: Vue 3 + Composition API
- **UI组件库**: Element Plus
- **构建工具**: Vite
- **AI引擎**: TensorFlow.js + MoveNet
- **状态管理**: Pinia
- **类型检查**: TypeScript

## 📋 使用说明

### 基本流程
1. **选择运动** - 选择俯卧撑或深蹲，设置训练时长
2. **授权摄像头** - 允许浏览器访问摄像头
3. **开始训练** - 点击播放按钮开始3秒倒计时
4. **AI检测** - 系统会实时检测您的动作（正在完善中）

### 开发者模式
- 在设置中开启"开发者模式"
- 可查看AI状态、FPS、置信度等技术信息
- 点击"日志"按钮查看详细的AI检测日志

### 功能按钮
- **设置** - 修改运动类型、时长和高级选项
- **成绩** - 查看训练历程和最佳成绩
- **帮助** - 使用说明和应用介绍
